## 2. Arquitectura TUI (Textual + rich)

- **Textual** = framework de la app (ventanas, menús, tablas, navegación).
- **rich** = renderizado de paneles/texto decorativo donde Textual no lo cubre (`Panel`, `Box`, markup).
- **Regla de estilo obligatoria:** todos los menús, listas, tablas y diálogos van **encerrados en rectángulos con borde** (`border` con título). Estilo consistente: `border: round cyan;` + `title` en cada contenedor.
- **Fondo:** usar el fondo predeterminado de la terminal del sistema. NO definir fondo oscuro propio ni sobrescribir el color de fondo de la terminal.
- **Sin InquirerPy**: se elimina de `requirements.txt`.

### Estructura (Textual App con Screens)
```
src/tui/
  app.py          → SpotifyManagerApp(App) — maneja navegación entre screens
  screens/
    __init__.py
    main_screen.py    → menú principal (OptionList) en contenedor con borde
    playlists.py      → Ver Playlists (+ tracks)
    import_screen.py  → CSV/TXT → Playlist
    dedupe_screen.py  → Limpiar repetidas
    sort_screen.py    → Ordenar playlist
    top_screen.py     → Top artistas/canciones
    export_screen.py  → Playlist → CSV/TXT
  widgets.py      → helpers: rectángulos/bordes reutilizables (bordered_container, bordered_table)
```
- Navegación: `app.push_screen(...)` / `pop_screen`. Bindeo básico: `q` = volver/atrás, `Enter` = seleccionar.
- Menú principal: `OptionList` dentro de un contenedor `border` con título `🎵 Spotify Manager` y footer de instrucciones.
- Listas de playlists/tracks: `DataTable` dentro de rectángulo con borde y título (nombre de playlist).
- Diálogos de confirmación (dedupe/sort): `Screen` modal con panel `border` y botones `Sí/No`.

## 4. `src/spotify_client.py`

### 4.1 Scopes en `get_auth_url()`
`playlist-read-private playlist-modify-public playlist-modify-private user-top-read`

> ⚠️ Requiere **re-autenticación una vez** (el token actual solo tiene `playlist-read-private`). Añadir aviso claro en la UI cuando una operación falle con 403.

### 4.2 Métodos nuevos
- `create_playlist(name: str, public: bool = False) -> str|None` → POST `/users/{user_id}/playlists` body `{"name","public","description":""}` → devuelve `id`.
- `search_track(artist: str, name: str) -> str|None` → GET `/search?q=track:{name} artist:{artist}&type=track&limit=1`. Fallback: buscar solo por título (`q=track:{name}`). Chequear caché `track_uris.json` antes de llamar a la API (`key = f"{artist.lower()}|{name.lower()}"`); guardar en caché tras resolver.
- `add_tracks(playlist_id: str, uris: list[str])` → POST `/playlists/{id}/tracks` con `{"uris": [...]}`, lotes de 100.
- `remove_tracks(playlist_id: str, uris: list[str])` → DELETE `/playlists/{id}/tracks` con `{"tracks":[{"uri":...}]}`, lotes de 100.
- `get_top(kind: str, time_range: str, limit: int) -> list` → GET `/me/top/{kind}` con `time_range` (`short_term|medium_term|long_term`), paginado hasta `limit` (máx 50 por página).
- `get_playlist_tracks()`: añadir campo `added_at` a cada track (de `item["added_at"]`).

## 5. `src/csv_handler.py`

- `write_csv(filepath, tracks)` → cabeceras exactas `Track Name`,`Artist Name(s)` (formato export de Spotify, re-importable). Artistas separados por `;` si hay varios.
- `write_txt(filepath, tracks)` → una línea `Artista - Canción` por track.

## 6. Screens (cada uno en rectángulo con borde)

Helper compartido: `pick_playlist(client) -> playlist|None` (selector de playlists en `DataTable` con borde) reutilizable.

### 6.1 Importar — CSV/TXT → Playlist
1. Seleccionar archivo de `CSV_DIR` (rectángulo con lista) o ruta manual.
2. Parsear (`csv_handler.read_tracks`). Si el TXT tiene URIs `spotify:track:`, usarlas directo.
3. Resolver URIs con `search_track` mostrando **progreso** (`Encontrados X/Y`); listar no encontrados.
4. Pedir nombre de playlist → `create_playlist` → `add_tracks` (lotes 100).
5. Resumen final en panel con borde.

### 6.2 Limpiar repetidas
1. `pick_playlist` → traer tracks.
2. Detectar dups por **URI** (opción extra: por nombre+artista normalizados).
3. **Diálogo de confirmación** (panel `border`) listando lo que se quitará (mantener 1ª ocurrencia) → `remove_tracks`.
4. Mensaje "N duplicados eliminados".

### 6.3 Ordenar playlist
1. `pick_playlist` → traer tracks.
2. Criterio en rectángulo: **Título / Artista / Álbum / Duración** + orden **asc/desc**.
3. Ordenar localmente; reordenar vía delete-all + re-add (lotes de 100), **con confirmación** que avisa del riesgo (los tracks se quitan y se vuelven a añadir en el nuevo orden).
4. Mensaje de éxito.

### 6.4 Top artistas/canciones
1. Tipo: **Artistas / Canciones** (toggle en rectángulo).
2. Rango: **4 semanas** (`short_term`) / **6 meses** (`medium_term`) / **todo el tiempo** (`long_term`).
3. `DataTable` con borde con top N (20).
4. Botón **crear playlist con este top** (`create_playlist` + `add_tracks`).

### 6.5 Exportar — Playlist → CSV/TXT
1. `pick_playlist` → traer tracks.
2. Formato **CSV / TXT** (rectángulo con opciones).
3. Escribir en `CSV_DIR` con nombre sanitizado (`<playlist>.csv|.txt`, caracteres inválidos `/\:*?"<>|` → `_`).
4. Mostrar ruta absoluta del archivo generado en panel con borde.
